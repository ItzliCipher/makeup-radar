# Makeup Radar (website edition)

Search the newest, most advanced makeup. Every search checks the launch catalogs of about 60 makeup brands and beauty shops, plus launch news from Google News, Bing News and six beauty publications, live.

## Put it online for free (about 10 minutes)

1. **Make a GitHub account** at [github.com](https://github.com) (skip if you have one).
2. **Create a repository:** click **+** (top right) → **New repository** → name it `makeup-radar` → leave it **Public** → **Create repository**.
3. **Upload these files:** on the new repository's page, click **uploading an existing file**. In Finder, open this folder, select everything inside it (⌘A), drag it onto the page, then click **Commit changes**.
4. **Make a Render account** at [render.com](https://render.com) and sign up with your GitHub account.
5. **Create the website:** in Render click **New** → **Web Service**, choose your `makeup-radar` repository, pick the **Free** instance type, then click **Deploy Web Service**.
6. **Wait for the first build** (a few minutes). Render then shows your address, something like `https://makeup-radar-xxxx.onrender.com`. That's the link to share.

## Good to know

- On Render's free plan the site **goes to sleep after 15 minutes without visitors**. The next visit wakes it in about a minute; the page says "Waking up the search server…" while it does.
- The first search after waking takes a little longer while it checks every brand.
- Visitors' saved products and recent searches stay in their own browser. The site keeps no record of searches.
- To update later, upload new versions of the files to the same repository; Render rebuilds automatically.
